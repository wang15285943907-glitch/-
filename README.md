# 青岚并发山谷：同步互斥动画游戏

一个无需依赖、打开浏览器即可玩的操作系统同步与互斥互动游戏。玩家亲自调度进程，不靠答选择题推进：角色沿执行轨道移动，缓冲区、信号量、资源占用和等待队列随每一步实时变化。

## 怎么玩

- 点击角色卡片里的「执行一步」，亲手安排并发进程顺序。
- 「自动轮转」可连续播放；速度按钮可在慢速、标准和快速之间切换。
- 「撤销一步」回到上一次操作前；「重置本关」重新开始当前场景。
- 信号量卡片会显示可用数量、持有者和等待队列。
- 「操作图鉴」解释 P/V、互斥锁、计数信号量和游戏控制方式。
- 修炼值与关卡解锁保存在当前浏览器的 localStorage 中。

## 山路关卡

| 关卡 | 实际操作 | 练习重点 |
| --- | --- | --- |
| 竹林供需 | 调度生产者与消费者运送三件货物 | empty、full、mutex 与 P/V 顺序 |
| 满仓险路 | 复现持锁等待，再换安全次序疏通缓冲区 | 死锁形成与安全次序 |
| 批次行商 | 两位消费者竞争批次锁，各自连续取完一批 | 2014 年 408 OS 第 47 题型：整批互斥与单次缓冲区互斥 |
| 单格传信 | 先写后读一个数据包 | 2024 年 408 OS 第 46 题型：用 dataReady 表示先后关系 |
| 互斥改写 | 调度两位修订者更新同一份数据 | 共享数据修改的临界区互斥 |
| 共享阅览室 | 两位读者共享阅览席，修订者取得全部席位后独占写入 | 多读者并行、写者独占、计数信号量 |
| 五侠争叉 | 先制造环形等待，再按资源编号有序申请 | 哲学家就餐、循环等待与资源排序 |

真题关卡保留推理考点，重写了场景、参数和互动流程，不整段搬入原题。

## 自由沙盘

在侧边栏打开「自由沙盘」，可以配置缓冲区容量（1–6 格）、生产轮数（1–5 轮）和初始库存。进入后可手动调度或自动轮转；满仓开局配合危险申请顺序，可以观察持锁等待和死锁。

沙盘可以反复重置和撤销，不影响关卡解锁。

## 运行

直接用浏览器打开 `index.html`，不需要安装依赖或连接网络。

需要在线访问时，可以在 GitHub Pages 中将发布来源设为 `main` 分支根目录。
