# 青岚山水行记：同步与互斥

一个无依赖的浏览器练习游戏，按用户笔记中的六步法学习信号量 PV 操作。界面采用山水墨绿蓝色，进度、研习值与错题记录保存在当前浏览器的 localStorage。

## 训练模式

- **山水行记**：六步地图，随时从任一关开始或回看。
- **主线闯关**：进程分类、PV 排序、信号量初值、死锁判断与完整解法。
- **真题秘境**：改编 2014 年 408 操作系统第 47 题型和 2024 年第 46 题型，改写了故事、参数和交互形式。
- **并发沙盘**：逐条调度生产者/消费者操作，观察缓冲区、信号量、等待队列；可载入持锁等待的死锁演示。
- **随机试炼**：随机改变缓冲区容量和批量取货数量，重新推导初值与安全 P 顺序。
- **错题回看**：记录错题和下一次检查方向。

## 运行

直接用浏览器打开 \`index.html\`，不需要安装依赖、配置 API 或连接网络。游戏过程保存在本机浏览器。

需要在线访问时，可以在 GitHub Pages 中将发布来源设为 \`main\` 分支根目录。
