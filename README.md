# 青岚并发山谷：同步互斥动画游戏

一个无需依赖、打开浏览器即可玩的操作系统同步与互斥小游戏。玩家亲自调度进程，不靠答选择题推进：每执行一步，角色沿轨道移动，缓冲区和信号量即时变化；进程可能继续、阻塞、唤醒，也可能形成死锁。

## 怎么玩

- 点击角色卡片里的「执行一步」，手动安排生产者、消费者、写手、读手或修改者的执行次序。
- 点击「自动轮转」，观察系统交替调度进程。
- 查看共享缓冲区、信号量数值、等待状态和并发轨迹。
- 试错后可以重置或更换执行顺序；通关会解锁后续关卡并累计修炼值。

## 山路关卡

| 关卡 | 实际操作 | 练习重点 |
| --- | --- | --- |
| 竹林供需 | 调度生产者与消费者运送三件货物 | empty、full、mutex 与 P/V 顺序 |
| 满仓险路 | 复现持锁等待，再换安全次序疏通缓冲区 | 死锁形成与避免 |
| 批次行商 | 两位消费者竞争批次锁，连续取完一批 | 2014 年 408 OS 第 47 题型：整批互斥与单次缓冲区互斥 |
| 单格传信 | 先写后读一个数据包 | 2024 年 408 OS 第 46 题型：用 dataReady 表示先后关系 |
| 互斥改写 | 调度两位修订者更新同一份数据 | 共享数据修改的临界区互斥 |

真题关卡保留推理考点，重写了场景、参数和互动流程，不整段搬入原题。

## 运行

直接用浏览器打开 `index.html`，不需要安装依赖或连接网络。修炼值、已解锁关卡和通关记录保存在当前浏览器的 localStorage。

需要在线访问时，可以在 GitHub Pages 中将发布来源设为 `main` 分支根目录。
